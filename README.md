# ООО «Скуф и сыновья»

Барбершоп с пивным баром для мужчин 35+. «Вернём тебе 2007-й».

Учебный проект. Сайт: https://q7n3t.github.io/skuf-i-synovya/

## Структура

```
index.html            разметка, все тексты, SVG-иконки (спрайт в начале body)
deck.html             презентация-защита (css/deck.css, js/deck.js, js/deck-ui.js, js/deck-stats.js)
privacy.html          политика обработки персональных данных
documents/            пакет документов ООО (.docx) и архив
404.html              своя страница 404
css/main.css          токены, база, сетка, компоненты и секции — по разделам с комментариями
css/easter-eggs.css   стили пасхалок, грузятся лениво
js/main.js            точка входа, порядок инициализации
js/modules/           по модулю на блок: boot, smooth, header, hero, odometer, marquee,
                      prices, puzo, team, booking, pointer, utils
js/easter-eggs.js     пасхалки, грузятся лениво, когда браузер свободен
assets/               шрифты (woff2), favicon, og.jpg, пиксельные портреты команды (assets/team)
vendor/               библиотеки, лежат в репозитории, сайт не зависит от внешних CDN
```

Сборки нет: GitHub Pages отдаёт файлы как есть. Локально:

```
python3 -m http.server 8000
```

и открыть http://localhost:8000 (модули ES не работают при открытии файла с диска).

## Презентация-защита

`deck.html` — презентация внутри сайта, 26 слайдов в стиле сайта: концепция, команда, юрлицо,
полный пакет документов (скачиваются прямо со слайда, `documents/`), штат, афиша бара, экономика, история интернета в мемах,
план запуска и финальный слайд с рикроллом.

- Листать: стрелки ← →, пробел, свайп, кнопки внизу. Во весь экран — клавиша F или кнопка справа вверху.
- Ссылка на конкретный слайд: `deck.html#7`.
- Рикролл играет прямо на слайде через официальный плеер YouTube. Если на защите нет доступа к YouTube,
  положите файл клипа в `assets/video/rickroll.mp4` — тогда сыграет он.
- Документы на сайте: `documents/*.docx` и архив `documents/skuf-i-synovya-dokumenty.zip`.

## Стек

- [ui-sdk](https://ui-sdk.dev) 0.1.0-beta.2 — диалоги, аккордеон, слайдер, сегментный контрол, тоглы (Apache-2.0)
- [GSAP](https://gsap.com) 3.12.5 + ScrollTrigger — анимации (стандартная лицензия GSAP, бесплатна)
- [Lenis](https://lenis.darkroom.engineering) 1.1.13 — плавный скролл (MIT)
- Шрифты Unbounded, Onest, JetBrains Mono через Fontsource (SIL OFL 1.1)

Всё движение отключается при `prefers-reduced-motion: reduce`. Без JavaScript страница показывает весь контент.

## Как заменить картинки самому

Все картинки — обычные PNG в папке `assets`. Чтобы заменить, достаточно загрузить свой файл **с тем же именем** поверх старого.

| Что | Файл | Размер | Как выглядит на сайте |
|---|---|---|---|
| Фон карты «Пузо Легенда» | `assets/legend.png` | 192×121 (пропорция банковской карты 1,586:1) | растягивается на всю карту, пиксели остаются чёткими |
| Аватарки команды | `assets/team/grekov.webp`, `dolnikov.webp`, `goncharenko.webp`, `klemeshev.webp`, `belobrov.webp` | 264×303 | пиксельный портрет на цветном фоне, без уменьшения |
| Превью ссылки в Telegram | `assets/og.jpg` | 1200×630 | картинка при отправке ссылки |

Рисовать удобно в Aseprite, Piskel (piskelapp.com, бесплатно в браузере) или Photoshop с инструментом «Карандаш». Сохранять в PNG без сглаживания. Размер лучше оставить тем же: если нарисовать, например, 384×242 для карты или 128×128 для аватарки — тоже сработает, главное сохранить пропорции.

Загрузка через сайт GitHub, без программ:
1. Открыть репозиторий → папку `assets` (или `assets/team`).
2. **Add file → Upload files**, перетащить файл с тем же именем.
3. Внизу **Commit changes**.
4. Через 1–2 минуты сайт обновится. Если видна старая картинка — обновить страницу с Ctrl+Shift+R (на телефоне — закрыть вкладку и открыть заново).

Если браузер упорно показывает старую картинку, в `css/main.css` (для фона карты) или в `index.html` (для аватарок) поменять цифру в конце адреса, например `legend.png?v=2` → `legend.png?v=3`. Это редактируется прямо на GitHub: открыть файл → значок карандаша → **Commit changes**.

## Обновление сайта

После любой правки JS или CSS запусти `python3 tools/bump-version.py` — он ставит одну версию `?v=…` на все скрипты, стили и импорты модулей. Без этого браузер может взять новый HTML со старым закешированным JS.
